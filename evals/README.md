# Evaluation cases

This folder stores small, authorized examples used to test prompts and
deterministic checks.

- `cases/strong-opening.md`: a candidate that should pass basic structural
  checks.
- `cases/weak-ai-opening.md`: a deliberately weak example that should trigger
  multiple warnings.
- `rubrics/chapter-quality.json`: machine-readable scoring weights.

Do not add copyrighted chapters, private user drafts, or recognizable style
imitation samples without explicit rights.
